## 1. Игровые сцены (Уровни)
В проекте присутствуют следующие карты (`.umap`):
*   **M_MainMenu** — главное меню игры. Является стартовой картой.
*   **M_LevelTwo** — основная игровая сцена (второй уровень).
*   **M_2DSideScrollerExampleMap** — демонстрационная карта из базового шаблона.

## 2. Объекты на основной игровой сцене (M_LevelTwo)
На сцене расположено 37 акторов: 
*   **Игрок:** `2DSideScrollerCharacter`.
*   **Окружение:** `GlobalPostProcessSettings` (постобработка), `Level1_TM` (тайлмап уровня), `InstancedFoliageActor` (декоративная трава/кусты).
*   **Фоны:** `BG_Sprite` (4 штуки) — параллакс-фоны.
*   **Интерактивные объекты:**
    *   `CheckPoint_BP`.
    *   `Coin_BP`.
    *   `Health_BP`.
    *   `JumpBoost_BP`.
    *   `MovingPlatform1_BP`, `MovingPlatform2_BP`.
    *   `Merchant_BP` (выступает как конец уровня).
    *   `Sign1_BP`.
*   **Враги:**
    *   `Enemy1_BP` (9 штук).
    *   `Enemy2_BP`.
    *   `IntelligentEnemy_BP`.
    *   `EnemySpawner_BP`.
*   **Служебные объекты:** `NetworkPlayerStart` (точка спавна игрока), `TriggerBox` (триггерная зона).

## 3. Объект Игрока (Player)
Объект `2DSideScrollerCharacter` (основан на C++ классе) состоит из следующих компонентов (видно в панели Details):
*   **Capsule Component** — коллизия персонажа.
*   **Sprite** — визуальное отображение персонажа (Paper2D).
*   **CameraBoom** — пружинный рычаг для камеры.
*   **SideViewCameraComponent** — сама камера, следящая за игроком.
*   **Arrow1** — вспомогательный компонент (вероятно, для указания направления взгляда).
*   **Character Movement** — компонент передвижения.

## 4. Скрипты (Blueprints)
В проекте активно используются Blueprint-классы (папка `Content/VLGS2DTemplate` и `Content/Demo`):
*   **2DSideScrollerCharacter** — главный скрипт игрока. Отвечает за передвижение, прыжки, получение урона и анимации.
*   **2DSideScrollerGameMode** — игровой режим, определяет правила игры (спавн, рестарт).
*   **BP_Enemy1 / BP_Enemy2 / BP_IntelligentEnemy** — логика поведения врагов (патрулирование, атака игрока при контакте).
*   **BP_EnemySpawner** — управляет появлением врагов на уровне.
*   **BP_Coin / BP_Health** — логика подбираемых предметов (начисление денег или восстановление здоровья при коллизии).
*   **BP_JumpBoost** — Подкидывает игрока вверх при коллизии.
*   **BP_MovingPlatform1 / 2** — скрипт движения платформ по заданному маршруту.
*   **BP_CheckPoint** — система сохранения позиции игрока при активации.
*   **BP_Merchant** — логика NPC-торговца (вероятно, открывает UI магазина при взаимодействии).
*   **BP_PlayerSave** — отвечает за сохранение прогресса игры.
*   **BP_Attack1Damage** — скрипт, наносящий урон игроку от вражеских атак.
