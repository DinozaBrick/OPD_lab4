## 1. Физические параметры
На основе настроек проекта (Engine -> Physics):
*   Default Terminal Velocity: 4000.0.
*   Default Fluid Friction: 0.3.
*   Physics Materials в настройках Surface Type не обнаружены (все стоят по умолчанию).

## 2. Роли Blueprint-объектов
*   Враги: `BP_Enemy1`, `BP_Enemy2`, `BP_IntelligentEnemy`. Являются опасными объектами. Имеют компонент коллизии, при пересечении с которым игрок получает урон (урон обрабатывается скриптом `BP_Attack1Damage`).
*   Препятствия (Полезные): `BP_JumpBoost`. При контакте с игроком изменяет вектор его движения (подбрасывает вверх), помогая преодолевать высокие стены.
*   Бонусы: `BP_Coin` (валюта, вероятно для торговца), `BP_Health` (восстанавливает здоровье персонажа).

## 3. Пользовательский интерфейс (UI)
В проекте реализован UI через Виджеты:
*   WB_MainMenu — главное меню.
*   WB_MainHUD — основной игровой интерфейс.
*   WB_GameOver — экран поражения.
*   WB_Merchant — интерфейс магазина при взаимодействии с торговцем.
*   WB_ChatWindow и WB_LearnMore — дополнительные UI окна для отображения текста и информации о разработчиках.
