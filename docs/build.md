## 1. Настройки сборки (Build Settings)
*   **Движок:** Unreal Engine 5.
*   **Платформы:** В настройках плагинов присутствует поддержка Android. По умолчанию проект ориентирован на Windows (Desktop).
*   **Default GameMode:** `2DSideScrollerGameMode`.
*   **Стартовая карта:** `M_MainMenu` (как для редактора, так и для собранной игры).

## 2. Пакеты и плагины (Package Manager / Plugins)
В проекте включено 234 встроенных плагина.
*   **2D** (необходим для работы спрайтов и Paper2D).
*   **AI** (для логики умных врагов).
*   **Android** (поддержка мобильных устройств).
*   **Animation** (19 плагинов, для анимации персонажей).
*   **Audio** (11 плагинов, работа со звуком).
*   **UI** (для работы виджетов UMG).

## 3. Структура папок и ассеты
*   **Config** — конфигурационные `.ini` файлы движка.
*   **Content** — основные игровые ресурсы:
    *   `VLGS2DSideScrollerTemplate` — базовая структура игры (папки Blueprints, Enemies, Merchant, MovingPlatforms, Pickups, SaveSystem и т.д.).
    *   `Demo/2DSideScrollerBP` — синие принты, карты и материалы из оригинального шаблона UE.
    *   **Ассеты спрайтов (Sprites/Textures):** 
        *   Персонаж (`MainChar`): кадры бега, прыжков, анимаций смерти и ближнего боя.
        *   Враги (`Enemies`): спрайты желе (Jelly), лиц (Face), пустых слотов (Blank).
        *   UI (`UI`): кнопки, HUD, окна.
        *   Тайлсеты (`Tileset`): множество тайлов (S_Tile...) для построения уровней, фоны, объекты окружения (надгробия, кусты, ящики).
    *   **Звуки (MusicAndSounds):** игровые звуки (WAV_GameSound), музыка уровней, звуки интерфейса.
    *   **Карты (Maps):** игровые уровни.
